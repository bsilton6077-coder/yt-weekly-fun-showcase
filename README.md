# FunTube Weekly

A YouTube-inspired website built as a static front-end with a weekly rotating video feed.

## What it includes
- MrBeast-style challenge cards
- Karl-inspired creator content
- Unstable SMP Minecraft videos
- Manhunt categories
- Hide-and-seek and moon collecting challenge cards
- More fun creator/community content

## Local preview
Open `index.html` in a browser, or serve the project with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
If you enable GitHub Pages in the repository settings, the site can be served at:

`https://bsilton6077-coder.github.io/yt-weekly-fun-showcase/`

This project is fully static and does not rely on any blocked or unsafe third-party media access.
